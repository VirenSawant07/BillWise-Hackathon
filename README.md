# BillWise-Hackathon
BillWise — Bharat Builds Tour hackathon (WeMakeDevs × AWS), Team VersionOne. Checks Indian medical bills against government price ceilings. I built the React 19 + Vite + Tailwind frontend (two core pages, UI and rendering fixes) for a serverless AWS stack: Amplify, API Gateway, Lambda, S3, DynamoDB, Textract, Bedrock.
